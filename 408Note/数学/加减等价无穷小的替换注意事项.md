# 一、准则
![[加减型无穷小能否替换的判定流程.png]]

求 $\alpha-\beta$ 型（$x\to x_0$）的极限时，设 $\alpha\sim\alpha_1$、$\beta\sim\beta_1$，则

$$\lim_{x\to x_0}\frac{\alpha_1}{\beta_1}\begin{cases}\neq 1 & \Longrightarrow\ \alpha-\beta\sim\alpha_1-\beta_1,\ \textbf{可以分别替换}\\[4pt] =1 & \Longrightarrow\ \textbf{禁止替换},\ \text{必须泰勒展开到主部不抵消的阶}\end{cases}$$

**口诀：比值不等于 $1$ 就能换，比值等于 $1$ 就别换。**&#8203;

# 二、不能替换的清单（都是"比值 $\to1$"，高频坑）

下表均为 $x\to 0$。**"错误做法"列即替换后主部被抵消、丢失真值。**&#8203;

| 表达式 | 错误替换（禁用） | 真实主部（泰勒结果） |
|---|---|---|
| $\tan x-\sin x$ | $x-x=0$ | $\sim\dfrac{x^{3}}{2}$ |
| $x-\sin x$ | $x-x=0$ | $\sim\dfrac{x^{3}}{6}$ |
| $\sin x-x$ | $x-x=0$ | $\sim-\dfrac{x^{3}}{6}$ |
| $x-\arctan x$ | $x-x=0$ | $\sim\dfrac{x^{3}}{3}$ |
| $\tan x-x$ | $x-x=0$ | $\sim\dfrac{x^{3}}{3}$ |
| $\arcsin x-\sin x$ | $x-x=0$ | $\sim\dfrac{x^{3}}{3}$ |
| $\arctan x-\sin x$ | $x-x=0$ | $\sim-\dfrac{x^{3}}{6}$ |
| $\ln(1+x)-x$ | $x-x=0$ | $\sim-\dfrac{x^{2}}{2}$ |
| $e^{x}-1-x$ | $x-x=0$ | $\sim\dfrac{x^{2}}{2}$ |
| $1-\cos x$ | $1-1=0$ | $\sim\dfrac{x^{2}}{2}$ |
| $1-\sqrt{\cos x}$ | $1-1=0$ | $\sim\dfrac{x^{2}}{4}$ |
| $\sqrt{1+2\sin x}-1-x$ | $\sin x-x\sim-\dfrac{x^{3}}{6}$ | $\sim-\dfrac{x^{2}}{2}$ |
| $\sqrt{1+x}-\sqrt{1-x}$ | $1-1=0$ | $\sim x$ |
| $\sin(\sin x)-\sin x$ | $x-x=0$ | $\sim-\dfrac{x^{3}}{6}$ |
| $\ln(1+\sin x)-\sin x$ | $x-x=0$ | $\sim-\dfrac{x^{2}}{2}$ |

依据：把各函数展开到相减后主部保留的最低阶，再逐项相减（详见第五节）。

**注意最后三行这类"复合型"**&#8203;：外层函数再包一层时，$\sqrt{1+2\sin x}-1$ 虽可替换成 $\sin x$，但它与 $x$ 的比值 $\to1$，所以整体仍禁止直接替换。

# 三、可以替换的清单（"比值 $\neq1$"，替换安全）

| 表达式 | 替换后 | 依据（$\lim\alpha_1/\beta_1$） |
|---|---|---|
| $\sin 2x-\sin x$ | $\sim 2x-x=x$ | $\dfrac{2x}{x}=2\neq1$ |
| $\tan 2x-\sin 3x$ | $\sim 2x-3x=-x$ | $\dfrac{2x}{3x}=\dfrac23\neq1$ |
| $\arcsin 2x-\arctan x$ | $\sim 2x-x=x$ | $2\neq1$ |
| $\ln(1+2x)-\ln(1+x)$ | $\sim 2x-x=x$ | $2\neq1$ |
| $\sin x-x^{2}$ | $\sim x$ | $\dfrac{x}{x^{2}}\to\infty\neq1$ |
| $\tan x-x^{3}$ | $\sim x$ | $\dfrac{x}{x^{3}}\to\infty\neq1$ |
| $(1-\cos 2x)-(1-\cos x)$ | $\sim 2x^{2}-\dfrac{x^{2}}{2}=\dfrac{3}{2}x^{2}$ | $\dfrac{2x^{2}}{x^{2}/2}=4\neq1$ |
| $e^{2x}-1-(e^{x}-1)$ | $\sim 2x-x=x$ | $2\neq1$ |

依据：第二节情形 (a) 的充分条件。

**格外牢记一条：乘除（因式）中替换永远安全。**&#8203;

$$\lim\frac{\alpha\cdot\beta}{\gamma}=\lim\frac{\alpha_1\cdot\beta}{\gamma}$$

依据：等价无穷小的乘法定理 $\dfrac{\alpha}{\alpha_1}\to1\Rightarrow\dfrac{\alpha\beta}{\alpha_1\beta}\to1$。 **“加减有风险，乘除随便换”** &#8203;——这是最容易记的分割线。

# 四、禁止替换时，四种标准处理手法

## 手法 1：泰勒展开到"主部保留"的阶（首选，万能）

$$\tan x-\sin x=\left(x+\frac{x^{3}}{3}+o(x^{3})\right)-\left(x-\frac{x^{3}}{6}+o(x^{3})\right)=\frac{x^{3}}{2}+o(x^{3})$$

依据：$\tan x$、$\sin x$ 的麦克劳林展开，展开到 $x^3$ 是因为前两阶（常数、一次）会全部抵消。

**展开到几阶的判断法：** 先看相减后最低保留到几阶——常数、一次项抵消就展开到三次项，若二次也抵消就继续往高阶展。

## 手法 2：有理化 / 恒等变形，把加减变乘除

$$\sqrt{1+\tan x}-\sqrt{1+\sin x}=\frac{\tan x-\sin x}{\sqrt{1+\tan x}+\sqrt{1+\sin x}}$$

依据：平方差公式 $a-b=\dfrac{a^{2}-b^{2}}{a+b}$。分母 $\to2$ 是**非零常数**，可单独取极限（乘除中可替换、可代入）。剩下分子 $\tan x-\sin x$ 再按手法 1 或 3 处理。

## 手法 3：提公因子，把加减变乘积（乘积中就能替换了）

$$\tan x-\sin x=\sin x\left(\frac{1}{\cos x}-1\right)=\sin x\cdot\frac{1-\cos x}{\cos x}$$

依据：提取 $\sin x$，通分 $1/\cos x-1=\dfrac{1-\cos x}{\cos x}$。

此时每一项都可替换（因为已化为乘积）：

$$\sin x\cdot\frac{1-\cos x}{\cos x}\sim x\cdot\frac{\dfrac{x^{2}}{2}}{1}=\frac{x^{3}}{2}$$

依据：$\sin x\sim x$、$1-\cos x\sim\dfrac{x^{2}}{2}$、$\cos x\to1$；乘积中替换合法（第四节末条）。结果与手法 1 一致 ✓

## 手法 4：洛必达 / 拉格朗日中值定理（适合 $f(a)-f(b)$ 型）

$$\sin x-\sin y=\cos\xi\cdot(x-y),\qquad \xi\ \text{在}\ x\ \text{与}\ y\ \text{之间}$$

依据：拉格朗日中值定理。可把两个同型函数的差直接转成"导数 $\times$ 自变量之差"，从而绕开替换问题。

# 五、总结

| 结构 | 能否替换 | 理由 |
|---|---|---|
| **乘除**（作为整体因式） | ✅ 永远可以 | 等价的乘法性质 |
| **加减**，替换后两项比值 $\neq1$ | ✅ 可以 | 主部未抵消，误差为高阶 |
| **加减**，替换后两项比值 $=1$ | ❌ 禁止 | 主部抵消，误差与结果同阶 |
| **加减**，其中一项是精确量（如 $x$、$1$） | ⚠️ 看比值是否 $=1$ | 同上 |

**一句话收尾：** 看到 "$\sim$" 想往 $\alpha-\beta$ 里代之前，先心算一下 $\lim\dfrac{\alpha_1}{\beta_1}$——**等于 $1$ 就住手，改用泰勒展开**；不等于 $1$ 就放心换。
